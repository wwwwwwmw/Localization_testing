# Manual Steps Checklist

## Chuan bi
1. Mo browser sach cache hoac private window.
2. Dat viewport can test (desktop/mobile).
3. Chon locale can test.
4. Chuan bi file ghi ket qua theo result-template.md.

## Quy trinh thuc hien cho moi case
1. Ghi Case ID va locale.
2. Thuc hien dung cac buoc trong scenario.
3. Chup screenshot truoc va sau thao tac neu can.
4. So sanh expected va actual.
5. Danh dau Pass/Fail/Blocked.
6. Neu fail, tao bug va dinh kem evidence.

## Cac buoc kiem tra co ban moi locale
1. Header/footer da dich day du.
2. Date format dung locale.
3. Currency format dung locale.
4. Khong text overflow o viewport hien tai.
5. Direction dung (ar=rtl, locale khac=ltr).
6. Khong co ky tu encoding loi.

## Trinh bay ket qua
1. Tong hop theo locale.
2. Tong hop theo domain (translation/date/currency/overflow/rtl/encoding).
3. Liet ke top 5 loi nghiem trong.
4. De xuat muc uu tien fix.
